# HYA-012 · 酒店角色轮廓与服务节奏

本轮延续四份 docs 规划及 HYA_ART_STAGE2、ART_POLISH_A、PEOPLE_WORDMARK_FIX 的实现。仅修改人物渲染，不重建经营系统、背景、UI 或存档。

## 角色与动作

- 六名代表角色：两名前台（短发/盘发）、一名礼宾、一名清洁员、两位住客。加宽肩胯与衣袖、裤腿，减少细长竖杆观感；角色高度略有差异。
- 前台深蓝西装、翻领与名牌，在登记动作中交替抬手指引；礼宾酒红双排扣制服、肩章、帽子、手提行李，停留时抬手迎客。
- 清洁员鼠尾草绿制服、围裙、口袋、盘发与拖把，清洁时前倾、错步、转腰；住客以米色/蓝绿外套、围巾、发型和行李箱区分，等候时轻微换重心、张望。
- 礼宾沿入口→前台外侧通道→电梯往返，节点停留；避开前台实体和左侧沙发/行李车。移动速度有起停缓冲，步态相位由实际路程驱动，静止时不再播放步行。
- RESERVED 客人在前台等候，OCCUPIED 后切至对应楼层房门并短距离入房；CLEANING 选择真实清洁房间。未活动的清洁员在右侧工作区待命。跨楼层仍是切镜式位置交接，不提供完整电梯上下行动画；不会画人物穿过楼板飞行。

## 资源与约束

沿用 11 关节骨骼、近/中/远 LOD 和六人上限。六份角色/服装变体网格复用同一顶点色材质；衣饰、箱包、拖把合并入人物网格，不单独增加道具 Draw Calls。降低头部球面与衣袖圆柱分段，抵消服装细节。没有新纹理、实时灯光或面部动画。远景简模保持服装差异，但不播放骨骼细节；最远 Sprite 仍为通用轮廓。

## 验证

单元测试验证骨骼权重、道具在内的落地包围盒、六人上限和状态只读；150 秒路线采样验证连续位移、累计路程、停留与前台避障。真实生产 WebGL 测试保留原经济、存读档、相机和 UI 回归；新增服务场景采帧。PR #13 的高画质截图测试在 GitHub SwiftShader 上耗尽 90 秒预算，扩大该用例到与现有美术采集相同的 180 秒，保留所有断言。

证据与实际运行数据见同目录 CHARACTER_SERVICE_VALIDATION.md。MOBILE_PERF_UNVERIFIED：云端 SwiftShader 不等于桌面 GPU 或 iPhone Safari；没有真机 30/60 FPS 达标结论。
