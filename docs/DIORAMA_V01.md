# 第一轮酒店场景与性能工具

新增可独立调用的 Three.js 酒店场景工厂，由后续试玩整合 PR 接入应用入口。所有几何、木纹、文字、人物贴图为代码原创生成，无运行时外部资源请求。

- 共享几何/材质；家具与城市按形状和材质实例化；扩建仅在结构键变化时重建静态模块。
- 三层客房加大堂、十二房容量；低剖面隔墙让床具和软装可见。视野随楼层适配。
- 固定 3/4 正交视角、限制旋转、滚轮与双指缩放、射线客房代理。
- 26 个角色池，近景简模、中景代理、远景 Sprite；Low/Medium/High 限制人物、DPR 和城市规模。
- FPS、帧时间 P50/P95、draw calls、三角形、分辨率、画质；保留最近最多 180 秒采样供导出。持续低帧率触发自动降级。

当前不是所有图形 Tickets 的完整验收：没有骨骼人物、完整进出电梯路径、烘焙光照贴图、施工动画、声音、24 房压力场景。场景仍为程序化几何的首轮视觉稿，需要用户确认后精修。

MOBILE_PERF_UNVERIFIED：尚无 iPhone Safari 真机测试；SwiftShader 回归不是目标硬件 FPS 证明。正式移动性能门禁保持未验收。

验证：独立类型检查、性能分位数/采样单元测试通过；实际应用端首帧与场景截图将在下一份整合 PR 提交。
