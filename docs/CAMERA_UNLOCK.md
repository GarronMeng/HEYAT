# 自由视角修复

用户在 2026-10-22 明确授权合并已验收的 PR，并要求解锁视角。PR #10、#11 已分别检查原 head CI 为 success 后合并；本补丁基于 main d07876545201ac2716f5a609561bcd539e2826db。

## 原因与修改

原 OrbitControls 把水平角限制在 0.34–0.85 弧度（约29°），俯仰角限制在0.8–1.15，且关闭平移，所以拖动很快触及边界，看起来像视角被锁住。

- 水平可连续旋转360°；俯仰允许接近俯视到接近水平，保持相机在地面上方。
- 开启平移：桌面右键拖动，手机双指拖动；左键/单指拖动旋转。
- 滚轮/双指缩放，zoom范围扩大到0.35–4。
- 一键重置回原有审核机位，先清除惯性，避免松手后继续漂移；第一次进入也保持原默认构图。
- 右键平移、双指操作和被取消的手势不再触发房间点选。
- 性能报告增加camera位置、target、zoom字段，方便复现视角，不保存或修改经营状态。

## 验证

新生产浏览器用例真实执行超过原角度边界的拖动、右键平移、滚轮放大及重置；检查报告中的角度/target/zoom和完整存档不变。单独用例1/1通过（22.2秒，Chromium141 / SwiftShader），默认机位仍可点选101客房。类型检查与构建通过。完整回归和远端CI以PR最终记录为准。
