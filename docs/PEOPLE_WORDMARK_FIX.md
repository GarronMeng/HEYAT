# 人物与 HEYAT 建筑标识修复

基线：main c7a079970f6872f93eea4cdb6006062f4e230d0c。依据用户 image(6).png 的实机反馈；保持已解锁的相机、经营系统、升级和v1存档。

## 已定位的问题

1. 屋顶与大堂字样使用 Sprite，始终朝向相机。相机解锁后，文字平面转离实体招牌并穿过其几何体，导致断字、重叠和悬浮。
2. 人物躯干/四肢大多用独立椭球，肘膝和腰部呈明显球节，头身与肩宽让放大画面像木偶。部分待命位置和房间内位置接近花盆/家具；无队列的客人会原地摆腿，行李员朝向用位置而非速度判断。

## 修复

- 两个品牌字样改为固定的实体平面，保留深度测试与正面显示；从侧面正常透视缩短，从背面不显示镜像字。屋顶采用完整 HEYAT / HOTEL 两级字标。
- 大堂字标移至前台柜台正面，以深色铜字和浅石材形成可读对比，避开楼板遮挡。客房编号仍为面向镜头的游戏提示，未混改。
- 标识纹理/几何/材质随建筑重建释放，避免升级和扩层累积未释放资源。
- 人物改用较连续的锥形制服/裤装轮廓，收窄肩宽与肢体、缩小头部，补领口/袖口/鞋和极简五官；继续共用四套网格、材质和11关节结构，每人一个近景Mesh。
- 清洁员待命点、排队客人和房间人物避开植物/桌椅；无事可做时使用待机，行李员按移动速度方向转身，降低步幅/摆腿速度。

## 验证范围

19/19单元测试、类型检查、lint、构建通过。人物几何测试增加肩宽边界，原骨骼索引/权重、地面落脚和状态只读断言保留。新增真实WebGL正面与低角度斜视图采集，并导出短程诊断报告；人工检查字标与牌面贴合、人物轮廓及植物穿插。经营全回归与远端CI结果记录于PR。
