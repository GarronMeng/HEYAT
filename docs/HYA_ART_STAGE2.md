# HYA-ART-02 / HYA-ART-03 · 人物与城市夜景阶段

> 基于 PR #8 的独立可审核叠加分支；不修改经营模型、存档、数值或 UI。

## 本轮可见变化

- 将原有身体由方块和细长棒状几何调整为 **正常微缩人体比例** 的四套原创建模风格：前台、行李员、客房清洁、住客。
- 角色躯干与装饰合并成共享 vertex-color 几何，移动时仅两条腿简单摆动；26 角色池继续使用近景 3D / 中景简模 / 远景 Sprite LOD。
- 夜景由重复 24 个黑色箱体建筑和实例窗户替换为一次生成的 1024×512 程序化城市背景纹理：渐层深蓝色天空、远近城市剪影、稀疏窗光、地面暖色街灯。
- 城市背景不产生额外逐帧场景 Draw Calls。没有新增外部 CDN、素材下载、反射后处理或角色骨骼。
- 保留原客房位置、人员数量、场景点击、存档兼容性、菜单与升级系统。

## 性能边界

- 人物近景每个主体 1 Mesh + 左右腿各 1 Mesh，不使用 26 份独立高面数资源。
- 背景为一张 GPU 纹理，其余城市实例化立方体已移除；作为取舍将原城市 mesh 空间视差改为轻量化画面深度。
- 与 PR #8 的 Low/Medium/High 材质设置兼容，继续以移动端 30 FPS 为真机测试门禁；软件 SwiftShader 不等价于 iPhone GPU。
- CI、浏览器真实截图与同设备画面评价通过后才考虑合并。
