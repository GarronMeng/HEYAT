# HEYAT 第一版试玩验收

日期：2026-10-22。用户已授权持续开发至第一版可玩 Demo，并在检查后合并。

## 已实现的完整玩家流程

首次引导 → 接待入住 → 唯一订单退房入账 → 脏房清洁 → 十二项数据驱动升级 → 自动入住 / 自动清洁 → 三层十二间客房 → 品牌三级且累计房费 ¥200,000 的有限终点。

功能包括本地自动保存、刷新恢复、损坏存档保护/导出、确认重开、后台暂停、1×/3×、单管理抽屉、客房目录/点击拾取、Low/Medium/High、持续低帧自动降级、上下文原位恢复与性能报告导出。无后端、遥测、外部 CDN、广告、充值或离线收益。

## 实际执行与证据

- Node 24.19.0 / npm 11.9.0；依赖沿用锁文件。
- `npm run typecheck`、`npm run build`、`npm run lint`：通过。
- `npm test`：14 项通过，含确定性状态、100,000 tick、重复结算/非法购买、存档、三策略可达性及性能分位数。
- `npm run test:e2e`：10 项通过。针对生产构建、Chromium / SwiftShader。
- 真实像素、零外部资源请求、WebGL 不可用、入口和模块加载失败及重试、上下文丢失/恢复均通过。
- 首单、清洁、升级扣款和刷新恢复通过；损坏存档保留和导出通过；390×844 无横向溢出；预置临界存档触发真实终局通过。
- 三种自动购买策略约 22.1–22.4 分钟通关；首次自动化 4.85–5.27 分钟，首次扩建 15.3–15.8 分钟。数据为模拟结果，不是人类试玩时长。
- `.github/workflows/ci.yml` 运行相同质量链路；远端运行结果以各 PR 的实际 Actions 为准，成功后记录在 PR。

场景与 UI 截图：`docs/evidence/v01-desktop.png`、`v01-mobile.png`、`v01-expanded.png`，均为测试生产构建的真实截图，扩建图由临界状态测试存档生成。截图不代表自然游玩或硬件性能达标。

云端交互浏览器无 WebGL 2，正确显示失败提示；成功渲染截图与回归来自本地 Chromium / SwiftShader。

## 性能采集方法（待真机执行）

1. 桌面 Chrome 与 iPhone Safari 各打开同一试玩 URL，记录设备/OS/浏览器与屏幕方向。
2. 初始与十二房成熟场景，分别保持 1× 连续营业至少两分钟，打开设置导出性能 JSON；报告含画质、实际分辨率、UA、renderer、FPS、P50/P95、draw calls、三角形。
3. iPhone 12/13 或用户指定设备连续运行 15 分钟，分别测试横竖屏、打开升级抽屉、触摸缩放/选房、切后台和恢复；记录热机后的表现与明显卡顿。
4. 切换 Low/Medium/High 比较视觉差异，检查现金、房态、存档不变。当前 Demo 不能替代 24 房最繁忙场景门禁。

**MOBILE_PERF_UNVERIFIED。桌面 60 FPS 与 iPhone 30 FPS 均未凭真实硬件数据验收。**

## 已知限制

画面是程序化简模的第一轮视觉稿，距目标概念图的半写实质感仍需精修。当前光影采用固定方向光/环境光与发光材质，没有全楼实时阴影。近景角色是比例简化的关节几何，并非骨骼模型；动画与进出路径待完善。3× 只缩短等待，不改变经济数值规则。

渲染模块约 604 KB / 157 KB gzip，Vite 500 KB 模块体积告警保留。画质自动降级有持续低帧门槛，但没有目标设备达标证据。

回滚通过 revert 对应 PR 并重新部署上一版静态产物；不得直接覆盖旧项目或修改旧游戏 bundle。
